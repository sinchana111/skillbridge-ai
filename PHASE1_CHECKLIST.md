# Phase 1 submission checklist

- [ ] Add your actual name(s) to README.md
- [ ] Create a new **empty** GitHub repository named `skillbridge-ai`
- [ ] Upload the **contents** of the `skillbridge-ai` folder (not the ZIP itself)
- [ ] Confirm README and code files appear on GitHub
- [ ] Copy your GitHub profile URL (`https://github.com/YOUR_USERNAME`)
- [ ] Copy your repository URL (`https://github.com/YOUR_USERNAME/skillbridge-ai`)
- [ ] Paste both into the organizers' Google Form before their extended Phase 1 deadline
- [ ] Save the confirmation / screenshot

The organizer's Google Form URL is not included in the provided rulebook; use the link they shared in your event group. The final deployed app link is for Phase 2, not Phase 1.
